# Guides

Steps for routine tasks, with the exact commands. Each links the spec that owns the rules.

- [change-a-component.md](change-a-component.md): change or add a ui-kit component, regenerate its manifest fields and graph, check and stamp.
- [add-a-token-or-theme-parameter.md](add-a-token-or-theme-parameter.md): add a theme parameter, a Panda token or a color default, and regenerate the outputs.
- [tune-and-hand-off.md](tune-and-hand-off.md): tune a theme in the jig, Copy the JSON, and apply it as a saved theme or new defaults.
