# Helsinki — visual identity references

This collection preserves the complete body of the City of Helsinki’s five public English visual-identity guideline pages as retrieved on **5 November 2026**, plus three complete linked documents. It is a website-guideline archive with supplementary books/decks, **not an original 226-slide brand book**.

## Source scope

The website series follows the published component order, including guidance, examples, resource links, glossary and administrative support sections. **HE001–HE127** are complete expanded accordion sections. **HX01–HX48** are the remaining introduction, artwork and section-header components. Heading-only and download-only captures are retained for completeness; they do not imply that an unseen template was inspected. Browser navigation, cookie banners and floating chat controls are excluded from the captures. Content, typography, arrangement and colors are not redesigned.

- [Discover the visual identity](https://www.hel.fi/en/decision-making/information-on-helsinki/design-and-digitalisation/helsinki-brand-and-visual-identity/visual-identity-guidelines/discover-the-visual-identity) — [offline source](../sources/discover-the-visual-identity.offline.html), [unaltered HTML response](../sources/discover-the-visual-identity.html).
- [Use basic elements](https://www.hel.fi/en/decision-making/information-on-helsinki/design-and-digitalisation/helsinki-brand-and-visual-identity/visual-identity-guidelines/use-basic-elements) — [offline source](../sources/use-basic-elements.offline.html), [unaltered HTML response](../sources/use-basic-elements.html).
- [Visual storytelling](https://www.hel.fi/en/decision-making/information-on-helsinki/design-and-digitalisation/helsinki-brand-and-visual-identity/visual-identity-guidelines/visual-storytelling) — [offline source](../sources/visual-storytelling.offline.html), [unaltered HTML response](../sources/visual-storytelling.html).

**HC01–HC03:** complete three-page Finnish *Helsingin kaupunginvaakuna* guide, linked by the City under coat-of-arms guidance. [Original PDF](../sources/coat-of-arms-2019.pdf), [official download](https://stplattaprod.blob.core.windows.net/strategiatalousprod/kaupunginvaakuna_ohje_2019.pdf). The filename supplies the 2019 date. English manifests interpret its Finnish instructions; the original remains authoritative.

**HT01–HT12:** complete twelve-page 2025 Camelot *Helsinki Grotesk Pro* specimen, linked by the City. [Original PDF](../sources/helsinki-grotesk-pro-2025.pdf), [official download](https://stplattaprod.blob.core.windows.net/strategiatalousprod/helsinkigroteskpro-info_2025.pdf). The cover prints 1/1 although the file contains twelve physical pages; locators use physical pages. This specimen describes the font, not a new set of city layout rules. Font software itself is not included.

**HI01–HI36:** complete 36-slide illustration example deck by Lille Santanen, linked from Download elements. [Original PPTX](../sources/illustration-examples.pptx), [derived PDF](../sources/illustration-examples.pdf), [official download](https://helsinki.contenthub.fi/NiboWEB/helsinki/getPublicFile.do?uuid=17525524&inline=false&ticket=582f54a747dd3cb4b0fd2c62d76bdd4d&type=original). The original PPTX is preserved. LibreOffice converted it to a PDF; PNGs were rendered from that PDF at 2× scale. Manifests identify each physical slide using the corresponding derived-PDF page. The source uses Office fonts including Arial; the rendering is a software conversion, not a publisher-provided PDF, and may differ from PowerPoint in typography or effects. All 36 rendered slides were visually inspected. The linked web page does not state a deck publication date.

## Fidelity, coverage and limits

- The five source pages contain **127 accordions and 48 remaining components**, reconciled with [the reading-order inventory](../sources/reading-order.json). Original page HTML, section text and captured metadata are retained. **211 distinct published image files** are stored under `sources/media/`; responsive duplicates are not separately catalogued. See [media inventory](../sources/media-inventory.json) for URLs and [section inventory](../sources/inventory.json) for captured image resolution/load checks. All captured images decoded successfully.
- PNG section captures preserve the live layout at a 1440-pixel browser viewport. Some sections are tall; open Full-size image to read them. The offline HTML companions preserve source text and local images in a simplified readable layout. They are clearly marked as archives, and their onward reference links still require a connection. The untouched HTML responses preserve original markup and remote URLs.
- The eight-minute introduction film’s external [Helsinki Kanava player](https://www.helsinkikanava.fi/fi/web/helsinkikanava/player/vod?assetId=224278697) returned **CloudFront 403 / Request blocked**. HX01 records the embed description and unavailable player, not observed motion. No playable film is claimed. The motion instructions elsewhere are inspected static examples.
- Public asset-bank links, internal intranet/Teams/Slack/Confluence resources, licensed fonts, editable production templates, stock libraries and the separate HDS, data-visualization and socially-aware-communications sites are onward resources. They are identified by the complete captured guideline pages but are not represented as ingested books. The three complete linked aesthetic guidance/example documents listed above are included; there is no claim to mirror the entire municipal resource ecosystem.
- Keep source discrepancies visible. The live basic-font section names five weights, the glossary describes an older four-weight family, and the 2025 specimen shows six including Extra Light. The specimen’s file list repeats Medium. The site contains unfinished placeholders, repeated chart-reset text, and a heading “Download templates for diplomas” above a place-card link (HE126). These have not been silently corrected in the images.
- Rule scope matters: coat-of-arms clearspace uses half the shield width; framed-logo clearspace uses the letter H. Video examples use their stated UHD template context; signage and video font weights differ. Color-material mismatches and language exceptions remain explicit in the relevant specs. Claims about accessibility are attributed to the source, not independent certifications.
