# Special Olympics

[Open the offline gallery](../index.html). Version 3.0 covers the organization’s brand platform, visual identity, applications and resources.

## Source and coverage

All 92 physical pages of the [local original](../special-olympics-brand-identity-guidelines.pdf) have a full-page PNG and a six-field manifest in PDF order, including any covers, dividers and blank leaves. PDF creation metadata records October 2024. The dynamic curve sequence occupies pages 46–50. Section titles and subtitles distinguish repeated headings.
