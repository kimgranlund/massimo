# O2 — 2023 brand refresh

[Open the offline gallery](../index.html).

## Source and scope

This collection preserves the complete distinct artwork sequence from [Neil Cooper’s O2 brand refresh case study](https://www.neilcoopr.com/o2-brand-refresh). The portfolio identifies the client as O2 Telefonica, the role as Creative Director and the project year as 2023. That year identifies the work; CDN upload dates are not treated as a different edition.

The source describes renewing the oxygen premise through the bubble, color and typography for digital use. Its sections cover bubble flexibility and interaction, expanded color, a bespoke typeface, and applications from screens to an arena. This is a designer’s selected case study, not a complete corporate brand manual or a statement of current O2 requirements.

## Inventory and media

- O01–O16 retain source order. Ten entries contain the directly published MP4s; six contain original still images converted losslessly to PNG.
- Each motion PNG is one unaltered frame from the matching clip. Poster timestamps and duration are recorded in the manifest and [asset inventory](../sources/inventory.json). Videos remain playable offline. Four spread-out frames from each clip were inspected to check its principal states and progression; descriptions do not claim exact easing or motion specifications.
- Original downloadable media remain in `sources/`. MP4 and WebM alternatives describe the same source clips, so only MP4 is retained. Responsive image sizes are deduplicated and the full 1818-pixel still sources are preserved.
- Website navigation, the decorative hand image and the unrelated project-logo navigation are excluded. All 16 distinct case-study artworks were retrieved successfully. There are no unavailable entries in this source sequence.
- Composite boards and paired application images remain intact. The catalog titles describe the artworks where the source does not print a title.

## Interpretation limits

Ingredient applications describe observed choices unless the case study states a requirement. No exact color values, mandatory color proportions, type specifications or easing values are inferred. Intent purpose tags cite the accompanying portfolio rationale. The source does not supply prohibited-use rules, so these entries do not receive Constraint tags merely for showing one composition. Product offers, devices and event details are historical presentation content, not verified current offers or events.

## Gallery maintenance

From the parent directory, run `python3 build-gallery.py O2 "O2" "2023 brand refresh · 16 case-study artworks, including 10 local motion clips."` after changing manifests. The gallery embeds its specifications and uses relative links, so it opens directly from disk without a server.
