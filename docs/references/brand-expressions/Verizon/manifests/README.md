# Verizon masterbrand case-study references

[Open the offline gallery](../index.html).

## Source and scope

This collection preserves the distinct visual sequence from [Jessie W. Lee’s Verizon Master Brand Redesign case study](https://www.jessiewlee.com/verizon-master-brand-redesign), describing work with R/GA. It is an historical portfolio case study, not a current Verizon standards manual. Visible guideline update dates range from September 2019 to August 2021. No single publication date for the whole portfolio series is asserted.

The page references a 300+ page PDF, more than 30 online guidance areas, and a 300+ icon library. None of those complete resources is exposed here. Only the published specimens, screenshots and one animation are ingested. Links pictured inside screenshots are artwork, not functioning local downloads. The revenue-growth chart is retained as case-study content; its underlying financial claim is not independently verified.

## Inventory and media

- Eighteen distinct references preserve the source sequence after deduplication. The initial cropped laptop hero repeats the later complete overview. VZ01 uses the complete overview image from source position 12. A repeated Color overview screenshot is also deduplicated.
- [The source inventory](../sources/inventory.json) retains all 20 original image URLs, source order, original dimensions, hashes and deduplication decisions. Downloaded originals remain in `sources/`.
- VZ03 preserves the original 325-frame GIF (12.43 seconds) and supplies an H.264 MP4 derivative for controlled offline playback. Its PNG is frame 100 from the original GIF. No animation was reconstructed. The animation was inspected at multiple positions through its duration.
- All other PNGs preserve the entire native image. Long page screenshots remain complete; open the full-size link for small text. Composite specimens remain together because their comparisons are the lesson.
- Every manifest includes source-backed reference purposes. Ingredient rules distinguish explicit historical instructions from observed examples. Inferred strategic benefits use “can.”

## Gallery maintenance

From the parent directory, run `python3 build-gallery.py Verizon "Verizon" "Historical masterbrand case study · 18 references, including one local animation. Guideline screenshots dated 2019–2021."` after editing manifests. The gallery uses relative paths and embedded specs, and opens directly from disk.
