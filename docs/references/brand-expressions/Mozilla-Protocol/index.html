P01  /  Typography

Typefaces by brand and role

Slide intent
Teach designers to choose a face for its reading role within a brand. The same letters can give a headline a distinctive voice and give supporting text a quieter rhythm.
Strategic value
Mozilla and Firefox can share the distinction between headlines and body text while giving each brand its own pair of faces. A reader moving between the brands can encounter both a familiar hierarchy and a different voice.
Demonstration
The left column pairs Mozilla Headline with Mozilla Text. The right pairs Metropolis with Inter. Every specimen shows the same letters from Aa through Hh in bold and regular. The role labels group the specimens horizontally.
Category
Typography
Practical value
Choose a headline and body pair for a Mozilla or Firefox page. Compare the shape of a matching letter across the row before judging the difference between the roles in a column.
Content islands
  1. Study header Identify the Protocol version and editorial study number. Place the descriptive title above the comparison.
  2. Brand headings Place Mozilla and Firefox above two equal-width columns. Align the start of each row across brands.
  3. Headline specimens Label the upper row Headlines. Set each name above the bold and regular letter excerpts from its published figure. Preserve the source specimen scale.
  4. Body specimens Repeat the same sample letters and arrangement for Mozilla Text and Inter. Keep the role label separate from the face name.
  5. Source line Identify the publisher and indicate that four specimen excerpts form the comparison.

P02  /  Typography

One set of roles, two type scales

Slide intent
Teach designers to match the apparent prominence of a heading across typefaces. Two faces at one numerical size can occupy a different visual place in the reading order.
Strategic value
Mozilla and Firefox can give the same title role comparable prominence across their websites while preserving each brand’s chosen face. Protocol assigns the larger title sizes to Mozilla Headline.
Demonstration
At a 16 px root, the standard desktop Title 2XL uses 76 px for Mozilla and 64 px for Firefox. Title MD uses 48 px and 40 px. Body MD uses 16 px in both columns, with line-height multipliers of 1.25 and 1.5 respectively.
Category
Typography
Practical value
Choose a semantic role first and read the size and line height from the relevant brand scale. The aligned rows show precisely which values change for that role.
Content islands
  1. Study header Identify Protocol 22.0.0 and title the two-column comparison.
  2. Brand columns Align Mozilla at left and Firefox at right. Use identical role names and position their specimens on corresponding rows.
  3. Large and medium title rows Set Title 2XL and Title MD in the two headline faces. Label each specimen with the family, pixel size and unitless line height from the standard brand scale.
  4. Body row Set Body MD in each brand’s text face at 16 px. Retain both line-height values in the labels.
  5. Scope note Mark the comparison as a standard desktop scale with a 16 px root. The board samples three roles.

P03  /  Application

Two marks in one navigation pattern

Slide intent
Teach designers to decide which parts of a shared navigation pattern should signal ownership. A stable set of controls can help visitors carry their bearings from one branded surface to another.
Strategic value
Mozilla and Firefox can distinguish publisher from product at the left edge of the header while keeping familiar menu actions and the Firefox download in corresponding positions.
Demonstration
The upper bar starts with the black Mozilla signature. The lower bar starts with the multicolor Firefox symbol and wordmark. Both show two sample menu labels on the left and a blue outlined Download Firefox button on the right.
Category
Application
Practical value
Compare both branded variants before changing a shared header. Use the preview to place the appropriate mark while preserving menu grouping and the position of the download action.
Content islands
  1. Study header Name the design system and the shared navigation pattern above the comparison.
  2. Mozilla header Place the Default component capture beneath the Mozilla label. Keep the full bar, including the mark, sample links and download action.
  3. Firefox header Place the Firefox variant directly below at the same width and scroll position. Align corresponding left and right content margins.
  4. Source line Identify both images as desktop navigation component excerpts.
