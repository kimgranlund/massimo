# Xfinity brand-purpose case study

[Open the offline gallery](../index.html).

## Source and scope

This collection preserves all fourteen primary artwork presentations on [venturethree’s Xfinity brand-purpose case study](https://venturethree.com/work/xfinity-brand-purpose), retrieved on 2026-11-05. It contains eight static artworks and six motion presentations in page order. It is an agency case study, not a complete corporate guidelines book. The page refers to a 2023 brand ranking but does not state an edition date for the artwork; the site’s copyright date is not treated as the design date.

The source text describes the X as a symbol of connection, light and color as expressions of the emotions and possibilities of connection, and simple, personal and awesome as unifying principles. Where those statements support an Intent purpose, the manifest explicitly attributes them to the accompanying agency text. Benefits not established by that text remain interpretations using “can.” The source supplies no production color ratios, minimum sizes or mandatory layout rules. Ingredient applications describe the observed examples rather than inventing corporate requirements.

## Media inventory

- X01–X14 follow the primary case-study media order. Navigation, tracking images and unrelated Sky, NOW and Tata Play recommendations are excluded.
- X01–X04 and X13–X14 retain the original public MP4 files. Their PNGs are unaltered midpoint frames, with timestamps and durations in the manifests. Each clip was visually inspected at five points spanning its duration. A sequence remains one reference so its arrangement and transitions can be understood together.
- X05–X12 use the highest-resolution image variant advertised by the page. Original WebP files are retained, and the complete decoded artwork is saved as PNG with no editorial crop or reconstruction.
- The responsive [portrait version of X01](../sources/x01-portrait.mp4) is retained as an alternate source. It repeats the same 15-second X and color sequence in a 1080 × 1350 format and is not counted as a separate lesson. The landscape version is used in the gallery.
- [The asset inventory](../sources/inventory.json) records original URLs, byte sizes, dimensions, durations and poster times. Signed video URLs may expire; the downloaded sources remain local. No primary case-study artwork was unavailable during ingestion.

## Gallery maintenance

From the parent directory, run `python3 build-gallery.py Xfinity "Xfinity" "venturethree brand-purpose case study · 14 references, including 6 local motion presentations. Edition date not stated."` after editing manifests. The gallery embeds its specs and uses relative local links, so it can be opened directly from disk.
