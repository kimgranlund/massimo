# Mastercard — Pentagram identity case study

17 distinct published artworks: 16 stills and one 5.2-second animation. Full accessible project visual inventory, in page order. This is the historical 2016 identity shown by the dated logo-evolution artwork, not the current Mastercard master guideline book.

Source: [Pentagram, Mastercard](https://www.pentagram.com/work/mastercard/story). Design credited on the source to Michael Bierut and Luke Hayman. Retrieved 2026-11-05.

The downloads retain the largest published signed CDN derivatives found in the page: 2000 × 1500 for body stills, a 1500 × 935 published crop for the hero, and the 960 × 960 MP4 rendition of the source GIF. Unsigned original URLs return 403; native pre-CDN originals are not represented as available. Responsive duplicates, blur placeholders, and unrelated next-project previews are excluded. No project visual was inaccessible. PNGs preserve these published compositions; MC17 uses a frame at 2.5 seconds, with the complete motion file retained and playable offline.

Every artwork was visually inspected. The animation was sampled across its 5.2-second duration. Source prose provides rationale where explicitly cited in `reference_purposes`; inferred benefits use “can.” Constraint entries are confined to stated color relationships and palette roles. Application mockups do not establish universal measurements, clear space, easing, or reproduction rules. The full master book, production color values, and complete motion specification are not supplied by this case study.

Open [the gallery](../index.html) directly without a server. All gallery media, manifests and motion are local. External URLs below are provenance only. Source rights remain with Mastercard/Pentagram and credited creators.
