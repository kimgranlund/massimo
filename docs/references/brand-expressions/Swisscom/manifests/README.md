# Swisscom — Moving Brands case study

[Open the offline gallery](../index.html).

## Source and edition

This collection preserves the complete accessible still-image sequence from [Moving Brands’ Swisscom case study](https://movingbrands.com/work/swisscom/). It is an agency retrospective covering identity development, printed applications, environments, sponsorship and digital-system work. The page metadata gives publication as May 31, 2023 and modification as March 24, 2026. Those are webpage dates, not dates for every pictured application. No complete guideline book is supplied by this source.

The series is specifically the historical Moving Brands work. It is not a record of later Swisscom NEO or re.design identity work. No current corporate-standard status is implied.

## Inventory and limits

- SW01 is the original hero-video poster supplied by the webpage. SW02–SW08 are all seven inline artwork photographs or presentations, kept in source order. Each PNG preserves the complete original image and native dimensions. Composite images remain intact. No replacement artwork or motion frames were invented.
- Five video embeds appear in the source. Public player configuration retrieval returned HTTP 403 for all five. SW01 documents only the supplied poster for the hero video. The other four embeds have no image entry because no source artwork could be retrieved. Consequently this collection contains no playable clips and no motion timing or behavior specifications.
- Missing playable embeds, in source order: [hero / 866693300](https://vimeo.com/866693300), [second block / 866693333](https://vimeo.com/866693333), [third block / 866693352](https://vimeo.com/866693352), [digital-system block / 866693380](https://vimeo.com/866693380), [final video block / 866693395](https://vimeo.com/866693395). The manifest `source_order` counts these video positions as well as images, so there are intentional gaps.
- The following-project Eir teaser, website navigation, decorative controls and repeated preload references are excluded.
- [Original asset inventory](../sources/inventory.json) records the exact download URLs and dimensions. The server returns WebP content for its JPG URLs; original bytes are therefore saved with `.webp` extensions. WordPress original-size images are used where available, up to 4200 pixels wide. SW02 is 980 × 568 pixels.
- Source URLs in this index require internet access. The gallery, PNGs, manifests and local originals work offline.

## Interpretation boundaries

The agency’s accompanying text supplies the one-axis rationale and the aims of unification, Swiss heritage and digital consistency. Purpose evidence attributes those explanations to the case study where they are not visible in an image. Inferred strategic benefits use “can.” Observed applications do not establish mandatory crop ratios, environmental dimensions or company-wide rules. The workshop photograph does not make its small interface details legible enough for detailed specifications.

## Maintenance

From the parent directory, run `python3 build-gallery.py Swisscom "Swisscom" "Historical Moving Brands case study · 8 still references, including one video poster. Five source videos were unavailable."` after changing a manifest. The HTML embeds its specifications and uses relative local links.
