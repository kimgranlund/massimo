# NN North Sea Jazz Festival

[Open the offline gallery](../index.html). This pilot selects three examples from Studio Dumbar’s identity project for the NN North Sea Jazz Festival. The studio describes custom code for animating text in both moving and still applications. The selections follow their order in the project case study and show the system on a transit poster, in a moving lineup and on a printed program. ## Source and reproduction

The day and year visible on the program are part of its printed design. The publication date of the case study is unspecified.
