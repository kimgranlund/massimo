# Nike Sportswear / Run — Holiday 2019

[Open the offline gallery](../index.html).

## Source and scope

This collection contains all **17 distinct artworks** in credited designer [Annie Nguyen’s Nike Sportswear / Run HO19 case study](https://annienguyen.net/Nike-Sportswear-Run-HO19), retrieved 2026-11-05. It is a historical campaign-layout case study, **not a complete Nike Sportswear identity guideline book**. NS01–NS09 are Sportswear Core; NS10–NS17 are the adjacent Run Core project published on the same page. The latter are explicitly identified as Run throughout the manifests.

The designer describes adapting supplied photographs to retail and digital layouts. Photographer authorship and image capture are not attributed to the designer. Store scenes are presented by the source as renderings, not evidence of installed stores. There are no motion assets or PDF downloads in this case study.

All original Cargo JPEGs are preserved under `sources/`; PNGs retain full original pixels, borders and presentation mattes. No source art was cropped, reconstructed or enlarged. All 17 images were visually inspected individually; the PNG/JPEG decoded pixels match. No duplicates were removed: reused subjects have meaningfully different compositions or applications. No case-study media was missing. Source HTML is preserved as provenance; it is not an offline mirror of the original website. Exact original URLs and dimensions are recorded in [source inventory](../sources/inventory.json).

## Unresolved full-book search

The complete Nike Sportswear master guidelines remain uncollected. Searches for exact-name brand guidelines, brand book and PDF material found credible book evidence but no verified complete downloadable edition:

- [Communication Arts: Nike Sportswear brochure](https://www.commarts.com/project/16746/nike-sportswear-brochure) identifies an Opolis internal launch book; an award entry is not a full book.
- [PaperSpecs: Nike Fleece Brand Book](https://www.paperspecs.com/gallery/marketing-collateral/tnanike-sportswear-fleece-brand-book-3/) identifies a 52-page AW77 publication; the article does not supply all pages or a full PDF.
- Search hits titled Nike Brand Guidelines at unrelated document-hosting domains had snippets describing unrelated books rather than verifiable Nike source pages; these were not accepted as authentic guidelines.
- Credited NSW retail and campaign sources were also located at Darrin Crescenzi, Barber Design and Lex Trickett. They are further source leads, not silently included as parts of this campaign.

The original wishlist should remain open for a complete Sportswear book. This collection adds a clearly scoped primary-designer source rather than replacing that request with generic Nike logo guidance.

## Refresh and portability

From the parent directory run `python3 build-gallery.py Nike-Sportswear "Nike Sportswear / Run — Holiday 2019"`. The gallery embeds every canonical manifest and uses only relative local links. Open `index.html` directly from disk. Source URLs in this README are provenance links, not runtime dependencies.
