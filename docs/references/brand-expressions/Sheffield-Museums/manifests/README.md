# Sheffield Museums

[Open the offline gallery](../index.html). The museum’s identity lets individual exhibitions choose accent colors and guest lettering within a shared system.

## Source and coverage

All 70 physical pages of the [local original](../sheffield-museums-design-guidelines.pdf) have a full-page PNG and a six-field manifest in PDF order, including any covers, dividers and blank leaves. The cover precedes printed folio 01. PDF pages 27, 32 and 58 correspond to printed folios 26, 31 and 57. The signage page presents indicative applications. PDF metadata records April 2022.
