# Halfkey slide manifests

Open the [slide gallery](../index.html) directly from disk. After changing the manifests or their order in this index, run `python3 build-gallery-data.py` from the Halfkey directory and keep the refreshed `gallery-data.js` alongside the HTML.

Each JSON file describes one slide using the [brand expression rubric](../../brand-expression-rubric.md). Each manifest links to its native-size PNG crop in the same directory. The source path points to the original contact sheet and is relative to the manifest. Row and column count from one, starting at the upper left.
