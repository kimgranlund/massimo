# Wise — Ragged Edge identity case study

[Open the offline gallery](../index.html).

## Scope and provenance

Complete distinct artwork sequence from [Ragged Edge’s Wise partnership case study](https://raggededge.com/partnerships/wise), retrieved 2026-11-05. This is a designer-authored case study of the 2023 rebrand and subsequent developments, including Wise Platform and later product examples. It is not a complete Wise brand book or current implementation specification. The source includes 2024 event content and assets named 2025; no single edition date applies to every artwork.

The collection contains **38 PNG/JSON pairs: 19 still artworks and 19 complete playable videos**. Originals, responsive alternatives, source HTML, extracted prose and retrieval URLs are preserved under [sources](../sources/). The published body order is used for WI01–WI38. Source asset indices refer to the extraction inventory, which begins with metadata and appends two video URLs stored outside the main Wise media directory.

The initial official lead `docs.wise.design` redirected to a 404 during research. `wise.design` exposes a JavaScript shell. This acquisition therefore uses the complete accessible main Ragged Edge case study instead of claiming access to the retired or unavailable guideline pages. The separate linked Wise Platform case study is outside this bounded source; its two presentations embedded in the main Wise page are included here. Site navigation, team portrait, footer film and unrelated agency graphics are excluded.

## Fidelity and interpretation

- Stills are native-size conversions from the largest published signed CDN rendition found in the page. Some originals use `.jpg` or `.png` filenames but the CDN returns WebP; PNGs preserve the decoded image pixels. No board was reconstructed or generated.
- All 52 original body/metadata assets were downloaded. Responsive duplicates are retained as sources but do not create duplicate references. Every remaining still was visually inspected; all videos were inspected across their duration with at least eight temporal frames, with a denser 24-frame inspection of the long design-system film. Audio is not analyzed.
- Videos are original downloaded MP4s. A PNG is one actual full frame, not a temporal contact sheet. The complete video is available in the gallery. Motion notes describe observed sequences without inventing timing or easing rules.
- Source text says Wise Sans supports 960 languages while the presentation film says 360 and includes another 342-language label. These different statements are preserved in their sources but are not reconciled or asserted as verified coverage.
- The agency prose claims accessibility beyond WCAG 3.0, whereas the film displays WCAG2/APCA labels. This collection does not endorse those compliance claims or treat them as a tested accessibility result.
- WI28 preserves a historical line-height rule visible around 51–52 seconds: large display 80%, smaller sub-headings 90%, intermediate sizes 80–90%. It is not generalized to body text or treated as current complete guidance.
- WI32’s flag/abbreviation film mixes country-style labels with BRL, a currency code. It is recorded as shown, not normalized into a supposedly consistent identifier system.
- Tiny photographic text is not transcribed where it cannot be read reliably. Strategic benefits use “can”; Intent purposes refer to source explanations; observed examples do not create mandatory constraints.
