# ITV / ITVX — DixonBaxi case-study series

[Open offline gallery](../index.html)

Source: [DixonBaxi — ITV](https://www.dixonbaxi.com/case-study/itv), retrieved 2026-11-05. This is the complete distinct visual series exposed in the case-study body, not a brand guidelines book. The page is undated and may evolve. Asset upload timestamps do not establish a design edition. Scope includes ITVX, the ITV masterbrand and the illustrated ITV1–4 / ITVBe identities; do not infer these are current mandates for every ITV property.

30 PNG/JSON pairs: 26 still artworks and 4 complete local MP4 clips. Originals are retained in `../sources/`; all four clips downloaded successfully. No missing case-study-body media was detected. Site navigation thumbnails and unrelated project tiles are outside this collection. Responsive URL sizes were deduplicated. One mobile rearrangement of the campaign composite and the static ITV1 video poster are retained as source files but do not create extra entries. The portrait hero is retained because its talent selection and message differ from the wide hero.

Each original composition remains intact. No contact sheet is substituted for a source artwork. Motion previews are single extracted frames; manifests record duration, selected frame timestamp and eight review timestamps spread across the clip. Analysis describes visual behaviour only; audio was not transcribed or evaluated. The case-study photographs of guideline screens are examples, not a complete readable guideline document. Small copy that cannot be read is not invented.

The source explicitly explains audience research, X amplification, typographic voices, channel individuality and motion clarity. `reference_purposes.Intent` attributes that contextual rationale. `slide_intent` and `strategic_value` remain interpretive. No Constraint purpose is assigned because these artworks state no enforceable limits. Observed arrangements are not promoted into requirements.

[Machine-readable provenance](../sources/inventory.json) records every original URL. Source copyrights remain with their respective owners; this is a local reference archive.
