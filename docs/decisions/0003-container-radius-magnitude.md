# 0003. Container radius as a magnitude of the concentric radius

**Context.** A container could not be sharper than fully rounded contents without breaking the concentric rule.

**Decision.** R = t × R0, t from 0 to 1 (theme radius-group, -collection, -card; the radius attribute per element, not inherited).

**Alternatives.** Named steps (concentric, soft, sharp, square); a separate container curvature scale.

**Consequences.** One continuous control that still follows the content's roundness.
