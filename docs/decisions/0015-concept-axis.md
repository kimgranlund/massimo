# 0015. Thirteen peer concepts organize the inputs

**Context.** Parameters were grouped by implementation, so a brief's vocabulary (density, elevation, vibrancy) had nowhere to land.

**Decision.** Thirteen concepts (scale, density, space, curvature, line, elevation, vibrancy, emphasis, typography, movement, state, iconography, adaptivity); each parameter group expresses one (contracts/parameters.json), with registry concept nodes.

**Alternatives.** One spec per concept; explain only.

**Consequences.** The Theme Schema's character layer (docs/planning/theme-schema.md) maps onto these concepts.
